## ⚡ Quick Start / 快速开始

```powershell
# 1. Clone the repository / 克隆源码
git clone https://github.com/YourUsername/TitanCore.git
cd TitanCore

# 2. Install dependencies & rebuild native addons / 安装依赖并编译本地模块
npm install

# 3. Compile C++ native extension / 编译 C++ 原生扩展
npm run build:native

# 4. Start in development mode / 启动开发环境
npm run dev
```

For detailed prerequisite requirements and distribution packaging, please read **[BUILD.md](BUILD.md)**.

详细的开发环境要求与正式打包指南，请阅读 **[BUILD.md](BUILD.md)**。
